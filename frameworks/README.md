## Usage

Start with [hiring-funnel/overview.md](hiring-funnel/overview.md) to understand how the stages connect, then read the individual stage files relevant to where you are in your search.

For coaching and career development, start with [1on1-coaching/overview.md](1on1-coaching/overview.md) to understand the 4-part coaching lens.
