# Hiring Funnel — Overview

The hiring funnel is a sequence of increasingly selective conversations. Each stage filters for different signals. Candidates who understand what is actually being evaluated at each stage can communicate their value more clearly.

## The Five Stages

| Stage | What Is Being Evaluated |
| --- | --- |
| [Résumé Review](resume-review.md) | Does this candidate clear the bar on paper? |
| [Recruiter Screen](recruiter-screen.md) | Is this a plausible fit for the role and company? |
| [Hiring Manager Screen](hiring-manager-screen.md) | Is this someone I'd want on my team? |
| [Technical Screen](technical-screen.md) | Can they do the technical work? |
| [Onsite](onsite.md) | Is this the right hire? |

## How to Use This Framework

Each stage has a different audience, a different goal, and a different set of signals. Preparing generically — grinding LeetCode without thinking about what a hiring manager actually needs to hear — is how strong candidates fail stages they could have passed.

Read the corresponding file before each conversation. For every stage, you will find:

- Who is evaluating you and what they actually care about
- What they can see directly and what they are inferring
- Where candidates typically lose signal
- How to communicate your real value clearly, without performing
