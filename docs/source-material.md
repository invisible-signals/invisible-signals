# Source Material

Invisible Signals builds on Annyce Davis's prior work teaching career growth, software development, technical hiring, and leadership development.

## Foundational Sources

- Introduction to Career Skills in Software Development
- Landing Your Next Gig in Tech
- Adventure Beyond the Keyboard: Growth Strategies for Senior Leaders

These materials inform the frameworks, prompts, examples, and diagnostic tools in this repository.

This project does not reproduce paid course content or copyrighted slide content verbatim. Instead, it translates the underlying concepts into open-source frameworks, templates, and AI-assisted workflows.
