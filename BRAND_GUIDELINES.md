# Brand Usage Guidelines

"Invisible Signals" is an open-source project created by Annyce Davis.

The repository contents are available under the Apache License 2.0. That license does not grant unrestricted rights to use the Invisible Signals name, logos, visual identity, or related brand assets.

## You May

- Fork and extend the repository.
- Reference Invisible Signals with clear attribution.
- Link to the official repository.
- Use the name in a descriptive way, such as "based on Invisible Signals."
- Build personal learning tools or internal educational materials using the repository contents.

## You May Not

- Present derivative work as the official Invisible Signals project.
- Use the Invisible Signals name, logo, or visual identity commercially without permission.
- Imply endorsement, sponsorship, certification, partnership, or affiliation without permission.
- Register confusingly similar domains, product names, social handles, or trademarks.
- Remove attribution or required license notices from redistributed materials.
- Use the brand in connection with deceptive interview preparation, fabricated experience, or misleading hiring claims.

## Naming Derivative Work

Derivative projects should use a distinct name and make their relationship to Invisible Signals clear.

Acceptable examples:

- "A personal study guide based on Invisible Signals"
- "An internal workshop adapted from Invisible Signals"

Avoid names that imply official status:

- "Invisible Signals Pro"
- "Official Invisible Signals Certification"
- "Invisible Signals AI"

## Brand Assets

Brand assets, when published, should live in [assets/branding](assets/branding).

Unless a brand asset file includes separate usage terms, these guidelines apply to use of the asset.

## Permission

For commercial use, partnership requests, certification programs, or use cases that could imply official affiliation, request permission from the project maintainer before using the Invisible Signals brand.
